ona-web now opens on an overview of your network, shows what each host serves and links to your other tools, has a page per location, and lists every address of a subnet. This release also fixes a stored XSS in the classic UI's host page.

## New

- **Overview page.** ona-web now opens on an overview, with counts of subnets, hosts, interfaces, DNS records, domains, VLANs, blocks, DHCP and DNS servers, and locations, each linking to its list. Below them are the active messages from every host and subnet. On a new install it also shows first steps. Shortcut: `g` then `g`.
- **Services on the host page.** For a server: the domains it is a DNS server for (master, slave or forward) and the subnets it serves DHCP for.
- **Links to your other tools on the host page.** ona-web reads the same host actions config as the classic UI (copy `www/workspace_plugins/builtin/host_actions/config.inc.php` to `www/local/config/host_actions.config.php` and edit it). Placeholders such as `%fqdn`, `%ip`, `%loc` and `%ca[attribute]` are filled in for each host. A link is hidden when a value it needs is missing for that host, so the example links that ship with ONA no longer point nowhere.
- **Location page.** Click a location to see its address, a map link from its coordinates, and the hosts there.
- **Every address of a subnet.** The subnet page lists each address as in use (with its host), free, DHCP pool, or network/broadcast. You can filter to in use or free, add a host at a free address in one click, and download the list as CSV (subnets up to 65,536 addresses). Works for IPv6 too.

## Fixes

- **A stale browser cookie no longer breaks ona-web.** If your browser held a cookie from another ONA installation on the same host, or from a database context that no longer exists, every page failed with "Database unavailable". ona-web now ignores the unknown context and uses the default one.

## Security

- **Stored XSS in the classic UI's "Host actions" box.** Links there can include a host's custom attribute values, and they went into the page unescaped. Anyone allowed to set custom attributes could plant script that ran for other users viewing that host in the classic UI (http://localhost:8080). The links are now escaped, and `javascript:` and similar links are dropped.

## Upgrading

No database changes. Stop ona-web, unzip the new release into a new folder, copy your `.env` file into it, and start it; the data is kept (see `README.txt`).
