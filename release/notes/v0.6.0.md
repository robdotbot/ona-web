A small release: export the host, subnet and DNS record lists as CSV, see your own account and permissions, and clear a host's whole config archive in one go.

## New

- **Export lists as CSV.** The Hosts, Subnets and DNS records pages have an **Export CSV** button. It downloads every row that matches the current search, filters and sort, up to 10,000 rows. Values a spreadsheet would treat as formulas (starting with `=`, `+`, `-` or `@`) get an apostrophe in front, so opening the file can't run anything.
- **My account page.** Open it from the user menu to see your username, groups and the permissions you have, and to change your password.
- **Delete all of a host's archived configs.** The config archive on the host page has a **Delete all** button (needs the `host_config_admin` permission).

## Upgrading

No database changes. Stop ona-web, unzip the new release into a new folder, copy your `.env` file into it, and start it; the data is kept (see `README.txt`).
